# This is an application create discord bot

## Feature

- Auto create poll with many restaurant
- Get link restaurant
- Get discord message and billing to google sheet

# How to run

1. Clone this repository
2. Duplicate `.env.example` to `.env` file and fill correct values
3. `cd discord-bot`
4. `npm install`
5. `npm run dev`

# Command

- Auto create poll: `/create-poll`
- Get link restaurant: `/get-link`
- Get discord message and billing to google sheet: `/billing`
